# zemyx | HSEQ — Demo

Maqueta visual de un ERP / SIG HSEQ (ISO 9001, 14001 y 45001).

- Sin backend: no guarda información en servidor.
- Login con usuario quemado.
- Pensada para oferta comercial / Vercel.

## Credenciales demo

- Usuario: `admin`
- Contraseña: `demo123`

## Local

```bash
nvm use 24
npm install
npm run dev
```

## Vercel

Framework: Vite. Build: `npm run build`. Output: `dist`.
