# CALIDA Demo

Maqueta visual de un ERP / SIG HSEQ (ISO 9001, 14001 y 45001).

- Sin backend: no guarda información en servidor.
- Login con usuario quemado.
- Solo para demostración local (no desplegar en VPS).

## Requisitos

- Node.js 24+

## Credenciales demo

- Usuario: `admin`
- Contraseña: `demo123`

## Cómo correr

```bash
nvm use 24
npm install
npm run dev
```

Abre `http://localhost:5177`
